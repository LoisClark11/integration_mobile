# TouchSkin

Skincare e-commerce app for browsing and ordering products.

## Features

- Browse products with categories and search
- Featured product carousel with promotions
- Product details with images and stock labels
- Shopping cart with realtime updates
- Checkout and order placement
- Order history and order details
- Account creation and sign-in
- Password reset via email link
- Profile management with avatar upload

## Download

Grab the latest Android APK from the [releases page](https://github.com/LoisClark11/integration_mobile/releases/latest) and install it on your device.
